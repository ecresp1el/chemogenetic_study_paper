# Group I unpooled-control sensitivity version

- Control distribution: `EYFP_Control_Media` only (n=11).
- `EYFP_Control` cells are not included in the ANOVA or Dunnett contrasts.
- Screen: exhaustive two-cell removals plus 3,000 seeded random removals at each size from 3 through 8 (seed `20260725`).
- Post hoc: Dunnett-adjusted Group I treatment contrasts versus `EYFP_Control_Media` within each removal set.

This version is intentionally separate from the pooled-EYFP-control analysis.
